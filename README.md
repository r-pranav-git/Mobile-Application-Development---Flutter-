# Mobile Application Development – Flutter

A collection of Dart programs and Flutter applications developed as part of the Mobile Application Development laboratory for the 2025–27 batch.

This repository documents practical implementations of Dart programming, Flutter UI development, animations, form validation, and Firebase Firestore integration.

## 📚 Lab Experiments

### CO1 – Installation and Flutter Fundamentals
- Flutter SDK installation and development environment setup.
- Simple Calculator application supporting addition, subtraction, multiplication, division, and clearing inputs.

### CO2 – Dart Programming
- Bill Splitter – Calculate the amount payable by each person.
- Random Password Generator – Generate passwords containing lowercase letters, uppercase letters, numbers, and symbols.
- Cows and Bulls Game – A number-guessing game that tracks correct digits and the number of guesses.

### CO3 & CO4 – Flutter UI, Widgets, and Animations
- Product Listing Application – Display product images, names, prices, ratings, and Add to Cart buttons.
- Animated Profile Card – Implement profile image animations, additional details, and a Follow/Following button.
- Student Registration Form – Create a form with input validation.
- Instagram Profile UI – Design a profile page with a bio, statistics, action buttons, highlights, and an image grid.

### CO5 – Database Connectivity
- Firebase Firestore Integration – Save student names and roll numbers as documents in the `students` collection.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK (included with Flutter)
- Visual Studio Code or Android Studio
- Android emulator or a compatible device

Verify your Flutter installation:

```bash
flutter doctor
```

### Run a Flutter Application

1. Clone this repository:

   ```bash
   git clone https://github.com/r-pranav-git/Mobile-Application-Development---Flutter.git
   ```

2. Navigate to the relevant Flutter project directory.
3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

**Note:** Run these commands inside a Flutter project directory containing `pubspec.yaml`. Dart console programs can be executed using `dart run filename.dart`.
